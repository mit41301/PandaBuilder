How to setup the Editor
-----------------------

1. install "cedt370r.exe"
2. copy "extensions.asm" into the folder "link" of the installation
3. copy "panda.key" and "panda.spc" into the folder "spec" of the installation
4. copy "panda_asm.cmd" into the folder "tools" of the installation
5. start the Editor
6. click "Tools -> Load User Tools -> panda_asm"
7. click "Tools -> Conf. User Tools" and set "Command" to the path of the HASM.exe file of the assembler
